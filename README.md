Use from maven

```
  <repositories>
    <repository>
      <id>jitpack.io</id>
      <url>https://jitpack.io</url>
    </repository>
  </repositories>


  <dependencies>
    <dependency>
      <groupId>com.github.ArseniyKorotkov</groupId>
      <artifactId>SeleniumAPI</artifactId>
      <version>master</version>
    </dependency>
  <dependencies>
```

Main class for use is
```
SeleniumDriverManager.java
```
